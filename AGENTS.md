## Agent skills

### Issue tracker

Las issues viven como ficheros markdown en `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Las cinco etiquetas por defecto (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `GLOSSARY.md` y `docs/adr/` en la raíz. See `docs/agents/domain.md`.

### Language

Code, comments, commit messages, branch names, PR titles and descriptions, and the README are in English. User-facing copy stays in Spanish, and domain terms keep the Spanish names from `GLOSSARY.md` (e.g. `Emisor`, `Destinatario`, `Borrador`) in code too. Specs, ADRs and issues stay in Spanish.
